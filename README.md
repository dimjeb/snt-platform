# SNT Platform

Платформа управления садоводческим некоммерческим товариществом (СНТ).

Поддерживает несколько СНТ на одном сервере (multi-tenant SaaS).

## Функциональность

- **Реестр членов и участков** — история владения, смены собственников
- **Учёт взносов** — членские, целевые платежи
- **Электроэнергия** — счётчики, показания, расчёт потерь в сети, начисления
- **Кабинет председателя** — управление организацией, члены, участки
- **Кабинет казначея** — начисления, платежи, отчётность
- **Личный кабинет члена** — просмотр долгов, передача показаний счётчика
- **Отчёты** — Excel: реестр должников, квитанции, список членов

## Стек

| Слой | Технология |
|------|-----------|
| Backend | Django 5 + Django REST Framework |
| Auth | JWT (simplejwt) |
| БД | PostgreSQL 16 |
| Очереди | Celery + Redis |
| Frontend | Vue 3 + Quasar (PWA, mobile-first) |
| Прокси | Caddy (автоматический HTTPS) |
| Деплой | Docker Compose |

## Быстрый старт

```bash
cp .env.example .env
# Заполнить .env

docker compose up -d
docker compose exec backend python manage.py migrate
docker compose exec backend python manage.py createsuperuser
```

После старта:
- API: `https://your-domain.ru/api/`
- Admin: `https://your-domain.ru/admin/`
- Документация API: `https://your-domain.ru/api/docs/`

## Роли

| Роль | Доступ |
|------|--------|
| `superadmin` | Все организации, системное администрирование |
| `chairman` | Полный доступ к своей организации |
| `treasurer` | Начисления, платежи, отчёты |
| `member` | Свои данные, показания счётчика |

## Расчёт электроэнергии

1. Снимаются показания всех счётчиков за период
2. Считается суммарное потребление каждого участка (текущие − предыдущие)
3. Потери сети = главный счётчик − сумма индивидуальных
4. Потери распределяются пропорционально потреблению
5. Начисление = (потребление + доля потерь) × тариф

При отсутствии показаний — используется среднее за 3 предыдущих месяца.
